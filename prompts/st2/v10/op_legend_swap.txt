[Legend Swap detection]
The likely manipulation is that two legend labels are exchanged between images.
Visual elements (line colours, bar fills, marker shapes) are IDENTICAL in both
images — ONLY the legend TEXT labels differ between them.

Step-by-step protocol:
  1. For evidence_id_1: list EVERY series as '[visual marker] → [exact label text]'.
  2. For evidence_id_2: do the SAME completely independently (Step 3 of the main
     protocol).  Read legend text directly from evidence_id_2; do not copy from 1.
  3. Compare: which visual markers have DIFFERENT label assignments?
  4. For the named series in the claim, find its VISUAL MARKER in each image, then
     trace that marker's behaviour (trend, peak, value at key x-values).
  5. The authentic image is the one where the named series' label is assigned to
     the visual marker whose behaviour matches the claim's assertion.
  6. The manipulated image assigns that label to a DIFFERENT marker — one whose
     behaviour does NOT match the assertion — making the claim appear false.

WHEN BOTH IMAGES APPEAR TO SATISFY THE CLAIM:
If the claim describes only behavioural outcome (e.g. 'model A outperforms B')
and both images show the entity named 'A' outperforming 'B' (just with different
colour markers labelled A), resolve using non-claim series:
  • List ALL label assignments in both images.
  • Find every label that differs between images.
  • Determine which complete assignment set is internally consistent with the
    caption (which describes the overall figure, not just the claim).
  • The authentic image has the globally consistent assignment.
  • Output ONE verdict and stop — do not loop.
